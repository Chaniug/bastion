# Monica 使用文档

欢迎使用 **Monica** —— 一款本地优先、开源的密码管理器。本文档帮助你快速上手核心功能。

## 快速开始

1. 从 [Releases](https://github.com/JoyinJoester/Monica/releases) 下载并安装 Android 应用。
2. 首次启动设置主密码（Master Password），它将用于加密本地保险库。
3. 主密码无法找回，请务必牢记。

## 添加凭据

- 点击右下角 **+** 按钮，选择「密码」类型。
- 填写标题、用户名、密码；可附上网址与备注。
- 建议使用内置密码生成器创建高强度随机密码。

## 自动填充

- 在系统设置中启用 **Monica 自动填充服务**。
- 在第三方应用或浏览器输入框聚焦时，Monica 会弹出填充建议。

## 双因素认证（2FA）

- 进入「验证器」页，点击 **+** 扫描服务商提供的 TOTP 二维码。
- 验证码每 30 秒刷新，临近过期时高亮提示。

## 同步与备份

- 通过 **WebDAV** 将本地保险库备份到自有服务器，实现跨设备同步。
- 支持从 **KeePass (.kdbx)** 与 **Bitwarden** 导入已有数据。

## 安全说明

- 所有数据默认完全离线，无需任何网络权限。
- 数据库采用 **AES-256-GCM** 加密，密钥由 Android Keystore（TEE）保护。
