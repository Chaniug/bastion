## 1. 背景与结论

用户问「安卓 app 的界面还能再好看一点吗」。基于代码体检（非渲染截图），结论：

- **配色体系已是顶配，不动**：12+ 套精选方案、Android 12+ 动态取色、OLED 纯黑、自定义配色生成器。
- **真正能提升观感的短板有 4 个**，按杠杆排序：**圆角体系统一**（最大）→ **排版字阶** → **组件质感与间距** → **动效增强**。

⚠️ **诚实边界**：本环境无 Android SDK、无法渲染，判断全部基于代码统计；**「好看」最终以你真机（荣耀 Android 17）验收为准**。每批改完构建 preview 包，你装上看，不满意逐 commit 回滚。

## 3. 方案（四方向）

### A. 圆角体系统一（最高杠杆，工作量最大）

1. 新增 `ui/theme/Shape.kt`，定义 Material3 语义形状：
   - `extraSmall = 4.dp` / `small = 8.dp` / `medium = 12.dp` / `large = 16.dp` / `extraLarge = 28.dp`
2. `Theme.kt` 的 `MaterialTheme(...)` 传入 `shapes = BastionShapes`。
3. **归一化硬编码圆角**（分两阶段，逐屏验证）：
   - 阶段 A1（低风险）：接入 Shapes 体系；归一最常见值 `12→medium`、`16→large`、`8→small`、`999/50→CircleShape`、`28→extraLarge`。这些值语义清晰、替换后观感几乎不变。
   - 阶段 A2（中风险，需真机验）：归一离群值 `14→12 或 16`、`18/20/22→16`、`4/6→extraSmall/small`、`10→8 或 12`、`24→24 或 extraLarge`、`32→extraLarge`。逐文件读上下文判断（按钮/输入框/卡片语义），改动前先列清单。
4. **目标**：界面圆角统一、层级分明（小控件 8、卡片 12~16、大容器/弹窗 28、胶囊 999）。

### B. 排版字阶规范化（低风险，高一致性）

1. 重写 `Type.kt`，用系统字体（`FontFamily.Default`，不引入字体文件，避免体积/版权）定义完整字阶：
   - `headlineMedium/Large`（大数字、品牌）、`titleLarge`（页面标题）、`titleMedium`（区块/卡片标题）、`titleSmall`（行标题）、`bodyLarge/Medium/Small`（正文）、`labelLarge/Medium/Small`（按钮/标签/说明）。
2. **收敛字重**：标题用 `SemiBold`、正文 `Normal/Medium`、标签 `Medium`，把 161 处 `Bold` 逐类降到合适权重（**需逐处读上下文**，分批做）。
3. 效果：信息层级清晰、标题不再「全粗体」。因全项目硬编码 fontSize 极少，改动主要靠 Theme 传导，风险低。

### C. 组件质感与间距（中风险）

1. **间距离群值清理**：`14.dp→12/16`、`18.dp→16`、`9.dp→8`（约 37 处，逐处看上下文）。
2. **卡片风格统一**：区分 `Card`（填充）/`OutlinedCard`（轮廓）/`ElevatedCard`（浮起）用途；统一卡片内边距（16dp）。
3. **页面留白统一**：列表页统一 16dp 水平边距；列表项图标容器、文本样式、分隔线统一。
4. **TopBar 规范**：标题字阶、返回/操作图标间距统一。

### D. 动效增强（中风险，克制）

1. 页面转场：Navigation Compose 的 `AnimatedContent` enter/exit（淡入+轻微位移，统一 easing：`FastOutSlowInEasing`）。
2. 列表项入场：`animateItem`（placement/fade）+ 首次加载淡入。
3. 按钮/FAB 按压反馈：scale 微缩（已有点击 ripple，补 scale 让手感更好）。
4. 原则：**密码管理 App 不做夸张动效**，只做「快、轻、不干扰阅读」的微交互。

## 5. 风险与边界（重点）

- **不牺牲数据密度与可用性**：列表不放飞间距、字号不缩水；这是一款密码管理 App。
- **圆角归一有轻微视觉变化风险**：A2 阶段逐文件读上下文、真机验收，不满意即时回滚（逐 commit `git revert`）。
- **不引入第三方字体/图标库**（体积与版权），除非你明确要求。
- **与 lint 清理计划互不干扰**：`docs/安卓端UI优化计划.md` 已全部完成；本次是新计划。
- **每批独立走**：dev → `Android CI debug` 绿 → 真机验收 → 合 main → 构建 preview 包。

## 6. 验证策略
